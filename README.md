Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty: one X quote post of make.fun's make-your-own-bounty post, with a photo of its own; POST.json names the post.

## How this entry was made

The post itself is a quote of make.fun's make-your-own-bounty announcement, published from the @Feng6v account with a photo of its own attached. The photo is a red poster-style cover for the bounty, and the post text carries the play code makefun-biscuit-spool-lily plus the link to make.fun's sponsor page, inviting readers to post a bounty of their own. POST.json in this repo points at the published post, and main.ts — written fresh for this entry — simply copies that file into the output folder so the grader can find the post and count its replies, reposts and quotes.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
